
# Application Bootstrap

## Purpose
The configuration layer for Laravel 12+. This file centralizes routing, middleware registration, and API-specific exception handling.

## Directory Structure

bootstrap/
├─ app.php                # Main bootstrap file for the application
├─ providers.php          # Registers service providers
├─ cache/
│   ├─ packages.php
│   └─ services.php
└─ docs/
    ├─ doc.md
    └─ bootstrap.md       # Implementation guide and code samples
